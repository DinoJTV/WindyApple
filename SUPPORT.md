# Support

## Bugs and feature requests

Open an issue at [DinoJTV/WindyApple](https://github.com/DinoJTV/WindyApple/issues).

For a bug, include:

- WindyApple version, if shown.
- Windows version and iPad model/iPadOS version.
- Steps to reproduce the problem.
- Expected and actual behavior.
- A redacted screenshot, only if it helps.

Please do not attach the paid executable, purchase receipts, order identifiers, license keys, or private screen content. Review logs before sharing them.

Feature requests should describe what you want to do and how the change would help.

## Purchases and downloads

The Gumroad product link is awaiting setup. When available, purchase and download-access questions should go to the seller contact listed on the product page or purchase receipt.

After purchase, use your receipt's download link or your Gumroad Library to access available files. See [Gumroad's customer guide](https://gumroad.com/help/article/282-how-do-purchases-work-for-my-customers.html).

## Security reports

Do not publish credentials or details that expose someone else's data in a public issue. Use the seller's private contact channel when available. A dedicated security contact has not yet been configured.
